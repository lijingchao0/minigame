# 蚂蚁修仙 v2.4

像素风、星露谷式俯视 RPG 微信小游戏。**横屏**游玩。纯 JavaScript Canvas 2D，无引擎、无外部库、无图片音频资源——全部程序化绘制。

## 运行步骤

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」→ 导入本项目目录
3. AppID 可使用测试号 / `touristappid`
4. 在模拟器中选择**横屏**设备（或真机横持），编译运行即可

首次运行进入标题 → **自动随机生成灵根** → 开始旅程；再次打开可「继续修仙」读档。

## 横屏说明

- `game.json` / 设计分辨率为 **landscape**，基准约 **812×375**（iPhone X 横屏比例）。
- 等比 contain 适配，必要时留黑边，避免拉伸变形；触摸坐标经 `screenToDesign` 换算。
- HUD 布局：左上状态、右上倍速+资源+小地图、**右下角**攻击/技能（右手拇指）、功能键在技能区左侧。
- 背包/任务等全屏面板为横屏左右分栏；对话居中偏下，宽度约屏宽 70%。

## 操作说明

| 操作 | 方式 |
|------|------|
| 移动 | **点击地图**自动寻路 / WASD |
| 普攻 | **右下角**圆形「攻」键 / A 或 J |
| 技能 | 右下角技能圆键（步/甲/丝/雷）/ 数字键 1–4、Q/E/R |
| 对话/采集/机缘 | 靠近目标后点击 |
| 背包/任务/修炼 | 技能区左侧「包」「志」「修」 |
| 灵根培养 | 背包 →「灵根」页签 |
| 区域切换 | 走到金色传送点 |
| **时间倍速** | 右上角 `1×/2×/3×/4×` 按钮循环切换 |
| **任务追踪** | 左上任务简讯；边缘箭头指引 |

### 饥荒式战斗（Don't Starve）

- **无接触伤害**：敌人贴身不扣血，可绕圈风筝。
- **攻击流程**：接近 → **蓄力前摇**（红环+身体后仰/抬爪/发光，约 0.55~0.8s）→ **挥击瞬间**才结算伤害 → 收招硬直（反击窗口）→ 循环。
- **可走 A**：前摇期间拉开距离则挥空无伤；玩家普攻可击退并打断小怪前摇。
- 玩家攻击：短前摇 + 可见挥击弧线 + 闪白/震屏/飘字/击退/粒子。
- 毒蜂等远程：可见弹道，可躲；多敌有分离，离开仇恨范围回巡逻。

### 主线自动接取

- 开局自动开始第一章「灵智初开」；每完成一章自动接下章并弹出「主线推进」横幅。
- 主线 NPC 只需对话推进/交付，无需再点「接受」。

### 新手教程

- 七步 overlay：走位 → 采集 → 背包 → 对话 → 修炼 → **战斗（走 A）** → 倍速。
- 战斗步文案与高亮已指向**右下角攻击键**，并说明前摇躲避。

### 角色视觉

- 程序化精灵系统（`js/entities/sprite.js`）：部件表 + 姿态帧（待机/走/攻/受击/死）。
- 玩家蚂蚁：三节体、触角、六足交替、大颚、灵光眼；装备改变外观。
- NPC/怪物各自昆虫特征强化，攻击前摇动画一眼可读。

### 时间流速

- 默认 **1 游戏日 = 12 现实分钟**（1×）；倍速 2×/3×/4× 即时生效。

## 灵根系统

- **开局随机**：单/双/三灵根；品阶下品→变异；七系金木水火土风雷。
- **后天培养**：背包「灵根」页进阶与用丹。

## 内容概览

- **地图区域 6** / **NPC 10** / **主线 7 章** / **支线 14**
- **境界 6×4**：凡蚁→灵蚁→妖蚁→蚁将→蚁王→蚁仙
- **技能 4**：灵步、甲壳护体、吐丝缚敌、微雷指

## 存档

使用 `wx.setStorageSync`，键名 `ant_xian_v2_save`。当前 **version: 5**（横屏与战斗不新增存档字段，结构兼容）。

**旧档兼容**：version ≤4 补 `tutorialDone` / 装备 `weapon`；更旧档补灵根等字段。
