# 蚂蚁修仙 v2.3

像素风、星露谷式俯视 RPG 微信小游戏。纯 JavaScript Canvas 2D，无引擎、无外部库、无图片音频资源——全部程序化绘制。

## 运行步骤

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」→ 导入本项目目录
3. AppID 可使用测试号 / `touristappid`
4. 编译运行即可游玩

首次运行进入标题 → **自动随机生成灵根** → 开始旅程；再次打开可「继续修仙」读档。

## 操作说明

| 操作 | 方式 |
|------|------|
| 移动 | **点击地图**自动寻路 / WASD |
| 普攻 | 底部圆形「攻」键（靠近敌人时浮现）/ A 或 J |
| 技能 | 底部技能圆键（步/甲/丝/雷）/ 数字键 1–4、Q/E/R |
| 对话/采集/机缘 | 靠近目标后点击 |
| 背包/任务/修炼 | 右侧「包」「志」「修」 |
| 灵根培养 | 背包 →「灵根」页签 |
| 区域切换 | 走到金色传送点 |
| **时间倍速** | 右上角 `1×/2×/3×/4×` 按钮循环切换；设置面板亦可改 |
| **任务追踪** | 顶部任务简讯；边缘箭头指引；点简讯或「志」打开日志 |

点击 UI 按钮/面板不会触发移动；点空白地图才寻路。靠近 NPC 时点击优先对话。

### 主线自动接取

- 开局自动开始第一章「灵智初开」；每完成一章自动接下章并弹出「主线推进」横幅。
- 主线 NPC 只需对话推进/交付，无需再点「接受」。
- 任务日志分 **主线 / 支线 / 已完成**；主线不可放弃；有主线时自动切回主线追踪。

### 新手教程

- 新档默认启用七步 overlay：走位 → 采集 → 背包 → 对话 → 修炼 → 战斗 → 倍速。
- 可点「跳过教程」；进度写入 `tutorialDone`。已完成第一章的旧档不再弹出。

### 装备外观与技能栏

- 项链/护甲/武器穿戴后即时改变蚂蚁外观（叶片链、木/石/铁甲壳、颚刃等）。
- 战斗区为圆形技能键组：普攻 + 已学技能；冷却扇形遮罩、灵力不足置灰；无敌人时自动隐藏/半透明。

### 时间流速

- 游戏内时间与**现实时间**同步：默认 **1 游戏日 = 12 现实分钟**（1×）。
- 倍速 2×/3×/4× 使游戏时间按倍数流逝；切换即时生效，存档保存当前倍速与游戏内时刻。

### 任务指引

- 自动追踪进行中的主线（或首个支线）；可在任务日志中手动点选追踪。
- 目标在屏外时显示边缘方向箭头；在屏内时在目标处显示标记。
- 跨区域时箭头指向通往目标的传送点；区域未解锁时提示繁荣度原因。

## 灵根系统

- **开局随机**：新档出生即定，不可自选。数量：单灵根 40%、双灵根 40%、三灵根 20%。
- **品阶**：下品 / 中品 / 上品 / 极品 / 变异（约 5%）。影响修炼速度；单灵根有纯净加成，三灵根略杂。
- **七系**：金木水火土风雷。变异灵根带唯一被动（如雷灵体：微雷指伤害 +30%）。
- **后天培养**：任务 / 打怪 / 机缘；背包「灵根」页可进阶与用丹。

## 内容概览

- **地图区域 6**：草丛草原、蚁巢洞窟、王国入口、露珠池塘、蘑菇森林、天敌边境
- **NPC 10** / **主线 7 章** / **支线 14**
- **境界 6×4**：凡蚁→灵蚁→妖蚁→蚁将→蚁王→蚁仙
- **技能 4**：灵步、甲壳护体、吐丝缚敌、微雷指（境界/任务解锁）
- **装备**：灵草项链、木甲、石甲、铁甲、颚刃（改外观 + 属性）

## 目录结构

```
game.js                 入口与主循环
game.json / project.config.json
js/pix.js               像素绘制工具
js/input.js             输入（点触寻路 + WASD）
js/engine/              镜头 / 瓦片 / 区域 / 寻路 / 过渡
js/world/regions/       六大区域地图数据（含机缘点）
js/entities/            玩家 / NPC / 敌人 / 物品 / 粒子
js/systems/             修仙 / 任务 / 战斗 / 教程 / 机缘 / 王国 / 存档 / 昼夜等
js/ui/ui.js             HUD、对话、背包、任务指引、标题等
```

## 存档

使用 `wx.setStorageSync`，键名 `ant_xian_v2_save`。当前 **version: 5**。

包含境界、灵根、机缘、背包与装备、任务、位置、王国繁荣度、时间倍速、**tutorialDone**、设置。

**旧档兼容**：
- version ≤4：按主线进度推断 `tutorialDone`；装备位补 `weapon: null`；外观由已穿装备 def.look 自动推导。
- version ≤3：昼夜倍速字段缺失时按当前真实时间折算。
- 无灵根新字段的更旧档，读档时按规则一次性补生成；已学技能按 `learned` 还原。
