# 蚂蚁修仙 v2.2

像素风、星露谷式俯视 RPG 微信小游戏。纯 JavaScript Canvas 2D，无引擎、无外部库、无图片音频资源——全部程序化绘制。

## 运行步骤

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」→ 导入本项目目录
3. AppID 可使用测试号 / `touristappid`
4. 编译运行即可游玩

首次运行进入标题 → **自动随机生成灵根** → 开始旅程；再次打开可「继续修仙」读档。

## 操作说明

| 操作 | 方式 |
|------|------|
| 移动 | **点击地图**自动寻路 / WASD |
| 攻击 | 底部「攻」按钮（靠近敌人时浮现）/ A 或 J 键 |
| 技能 | 底部技能格 / 数字键 1–3 |
| 对话/采集/机缘 | 靠近目标后点击 |
| 背包/任务/修炼 | 右侧「包」「志」「修」 |
| 灵根培养 | 背包 →「灵根」页签 |
| 区域切换 | 走到金色传送点 |
| **时间倍速** | 右上角 `1×/2×/3×/4×` 按钮循环切换；设置面板亦可改 |
| **任务追踪** | 顶部任务简讯显示目标；屏幕边缘箭头指引方向；点简讯或「志」打开日志，点任务可切换追踪 |

点击 UI 按钮/面板不会触发移动；点空白地图才寻路。靠近 NPC 时点击优先对话。

### 时间流速

- 游戏内时间与**现实时间**同步：默认 **1 游戏日 = 12 现实分钟**（1×）。
- 倍速 2×/3×/4× 使游戏时间按倍数流逝；切换即时生效，存档保存当前倍速与游戏内时刻。

### 任务指引

- 自动追踪进行中的主线（或首个支线）；可在任务日志中手动点选追踪。
- 目标在屏外时显示边缘方向箭头；在屏内时在目标处显示标记。
- 跨区域时箭头指向通往目标的传送点；区域未解锁时提示繁荣度原因，不显示死箭头。
- 无任务时简讯提示「去蚁后处接任务」。

## 灵根系统

- **开局随机**：新档出生即定，不可自选。数量：单灵根 40%、双灵根 40%、三灵根 20%。
- **品阶**：下品 / 中品 / 上品 / 极品 / 变异（约 5%）。影响修炼速度；单灵根有纯净加成，三灵根略杂。
- **七系**：金木水火土风雷。变异灵根带唯一被动（如雷灵体：微雷指伤害 +30%）。
- **后天培养**：
  1. **任务**：主线/支线奖励洗髓丹、觉醒丹、灵髓、妖丹等
  2. **打怪**：精英/Boss 概率掉落妖丹、灵髓；心魔可掉洗髓丹
  3. **机缘**：地图上金色旗帜光圈（灵泉/仙缘石/传承之地），靠近点击触发
- **培养界面**：背包「灵根」页签可查看效果、消耗材料进阶、使用丹药

## 内容概览

- **地图区域 6**：草丛草原、蚁巢洞窟、王国入口、露珠池塘、蘑菇森林、天敌边境
- **NPC 10**：蚁后、蚁王、工蚁长老、兵蚁队长、育婴蚁、侦察蚁、瓢虫商人、蚂蚱旅人、蜜蜂信使、萤火虫向导

## 存档

使用 `wx.setStorageSync`，键名 `ant_xian_v2_save`。当前 **version: 4**。

包含境界、灵根列表与品阶、机缘记录、背包、任务、位置、王国繁荣度、**时间倍速与游戏内时刻**、设置。

**旧档兼容**：
- version ≤3：缺少 `dayStartRealMs` / `speedMul` 时，读档以当前真实时间折算昼夜，保证色调连续，倍速默认 1×。
- 无灵根新字段的更旧档，读档时按规则一次性补生成。
