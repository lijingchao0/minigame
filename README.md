# 蚂蚁修仙 v2.1

像素风、星露谷式俯视 RPG 微信小游戏。纯 JavaScript Canvas 2D，无引擎、无外部库、无图片音频资源——全部程序化绘制。

## 运行步骤

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」→ 导入本项目目录
3. AppID 可使用测试号 / `touristappid`
4. 编译运行即可游玩

首次运行进入标题 → **自动随机生成灵根** → 开始旅程；再次打开可「继续修仙」读档。

## 操作说明

| 操作 | 方式 |
|------|------|
| 移动 | **点击地图**自动寻路 / WASD |
| 攻击 | 底部「攻」按钮 / A 或 J 键 |
| 技能 | 底部技能格 / 数字键 1–3 |
| 对话/采集/机缘 | 靠近目标后点击 |
| 背包/任务/修炼 | 右侧「包」「志」「修」 |
| 灵根培养 | 背包 →「灵根」页签 |
| 区域切换 | 走到金色传送点 |

点击 UI 按钮/面板不会触发移动；点空白地图才寻路。靠近 NPC 时点击优先对话。

## 灵根系统

- **开局随机**：新档出生即定，不可自选。数量：单灵根 40%、双灵根 40%、三灵根 20%。
- **品阶**：下品 / 中品 / 上品 / 极品 / 变异（约 5%）。影响修炼速度；单灵根有纯净加成，三灵根略杂。
- **七系**：金木水火土风雷。变异灵根带唯一被动（如雷灵体：微雷指伤害 +30%）。
- **后天培养**：
  1. **任务**：主线/支线奖励洗髓丹、觉醒丹、灵髓、妖丹等
  2. **打怪**：精英/Boss 概率掉落妖丹、灵髓；心魔可掉洗髓丹
  3. **机缘**：地图上金色旗帜光圈（灵泉/仙缘石/传承之地），靠近点击触发
- **培养界面**：背包「灵根」页签可查看效果、消耗材料进阶、使用丹药

## 内容概览

- **地图区域 6**：草丛草原、蚁巢洞窟、王国入口、露珠池塘、蘑菇森林、天敌边境
- **NPC 10**：蚁后、蚁王、工蚁长老、兵蚁队长、育婴蚁、侦察蚁、瓢虫商人、蚂蚱旅人、蜜蜂信使、萤火虫向导
- **主线 7 章 / 支线 14**：采集、交付、讨伐、守卫、护送、解谜等
- **境界 6×4**：凡蚁→灵蚁→妖蚁→蚁将→蚁王→蚁仙（各初期/中期/后期/圆满）
- **技能 4**：灵步、甲壳护体、吐丝缚敌、微雷指

## 目录结构

```
game.js                 入口与主循环
game.json / project.config.json
js/pix.js               像素绘制工具
js/input.js             输入（点触寻路 + WASD）
js/engine/              镜头 / 瓦片 / 区域 / 寻路 / 过渡
js/world/regions/       六大区域地图数据（含机缘点）
js/entities/            玩家 / NPC / 敌人 / 物品 / 粒子
js/systems/             修仙 / 任务 / 战斗 / 机缘 / 王国 / 存档等
js/ui/ui.js             HUD、对话、背包（含灵根页）、标题等
```

## 存档

使用 `wx.setStorageSync`，键名 `ant_xian_v2_save`。包含境界、**灵根列表与品阶**、机缘记录、背包、任务、位置、王国繁荣度与设置。

旧存档若无灵根新字段，读档时会按规则一次性补生成，不破坏进度。
